PORTFOLIO CASE / 品牌视觉设计

YANGTING / 2025

林里迷你门店

LINLEE MINI STORE

PROJECT OVERVIEW

随着茶饮品牌竞争从产品本身延伸至品牌体验与内容传播，传统静态周边较难持续激发用户参与。林里希望通过更具互动性和收藏属性的衍生产品，将消费者熟悉的门店、店员与品牌元素转化为可拼装的积木场景，在延续品牌识别的同时，拓展茶饮之外的互动与社交场景。

01 / 设计背景DESIGN BACKGROUND

从项目背景出发，
找到设计的核心问题。

随着茶饮品牌竞争从产品本身延伸至品牌体验与内容传播，传统静态周边较难持续激发用户参与。林里希望通过更具互动性和收藏属性的衍生产品，将消费者熟悉的门店、店员与品牌元素转化为可拼装的积木场景，在延续品牌识别的同时，拓展茶饮之外的互动与社交场景。

PROBLEM / 问题

设计挑战

传统静态周边较难持续激发用户参与，需要在延续品牌识别的同时，把门店、店员与产品元素转化为具有互动性和收藏属性的衍生体验。

SOLUTION / 解法

设计方案

将真实门店、店员形象与品牌视觉拆解为模块化积木语言，通过统一结构与标志元素建立可拼装、可组合并可持续扩展的品牌场景。

02 / 设计目标DESIGN OBJECTIVES

以“林里迷你门店”为核心，将品牌场景转化为具有可玩性与收藏感的积木产品。

通过模块化结构和统一的品牌元素，让消费者能够在拼装过程中重新体验品牌场景，同时兼顾产品展示、包装传播与后续系列化延展的可能性。

01核心目标一

强化品牌识别

提取门店造型、品牌Logo、员工服饰与标志性色彩，将真实品牌触点转化为具有辨识度的积木语言。

02核心目标二

提升互动体验

将传统静态周边转化为可拼装、可组合的互动产品，让消费者通过搭建过程增强对品牌场景的参与感与记忆。

03核心目标三

建立衍生体系

采用模块化设计逻辑，使门店、角色、陈列与产品元素能够持续扩展，为后续系列角色与场景开发预留空间。

FINAL OUTCOME / 设计成果

兼顾产品展示、包装传播与后续系列化延展，让消费者在拼装过程中重新体验品牌场景。
