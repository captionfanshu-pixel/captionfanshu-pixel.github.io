PROBLEM / 问题

设计挑战

在多种营销主题和空间尺寸中保持 IP 性格统一，同时让商品陈列足够清晰。

设计方案

02 / 设计目标DESIGN OBJECTIVES

明确目标，建立统一且有记忆点的视觉表达。

围绕品牌识别、内容传播与实际应用三个维度展开，让设计兼具视觉吸引力、信息效率与延展能力。

01核心目标一

强化视觉识别

建立清晰的核心符号与色彩记忆，让项目在不同媒介中保持一致。

02核心目标二

提升传播效率

优化内容层级和阅读路径，让受众快速理解项目主题与主要卖点。

03核心目标三

支持场景延展

形成可持续应用的视觉系统，适配线上、线下及后续衍生内容。

FINAL OUTCOME / 设计成果

形成覆盖内容传播、陈列道具、快闪空间与迷你店积木的系列化商业设计。
