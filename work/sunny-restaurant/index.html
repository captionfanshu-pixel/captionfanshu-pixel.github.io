晴日餐厅

SUNNY RESTAURANT

PROJECT OVERVIEW

以温暖的晴日餐厅为背景，通过拟人猫咪店员与柔和光影建立轻松治愈的品牌气质。

PLAYER ROLE角色 / 场景 / 品牌主视觉
STATUSCOMPLETED ●
01 / 设计背景DESIGN BACKGROUND

从项目背景出发，
找到设计的核心问题。

以温暖的晴日餐厅为背景，通过拟人猫咪店员与柔和光影建立轻松治愈的品牌气质。

PROBLEM / 问题

设计挑战

让角色、餐厅空间与品牌标识在同一画面中形成明确层级，同时保留生活感与故事感。

SOLUTION / 解法

设计方案

运用暖色木质场景、自然逆光和统一制服造型，塑造具有亲和力的餐厅角色世界。

02 / 设计目标DESIGN OBJECTIVES

明确目标，建立统一且有记忆点的视觉表达。

围绕品牌识别、内容传播与实际应用三个维度展开，让设计兼具视觉吸引力、信息效率与延展能力。

01核心目标一

强化视觉识别

建立清晰的核心符号与色彩记忆，让项目在不同媒介中保持一致。

02核心目标二

提升传播效率

优化内容层级和阅读路径，让受众快速理解项目主题与主要卖点。

03核心目标三

支持场景延展

形成可持续应用的视觉系统，适配线上、线下及后续衍生内容。

FINAL OUTCOME / 设计成果

形成可延展到海报、菜单、包装和社交传播的原创餐厅 IP 主视觉。
