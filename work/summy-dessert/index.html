01 / 设计背景DESIGN BACKGROUND

从项目背景出发，
找到设计的核心问题。

以一家夏日甜品店为舞台，构建明亮、亲切且具有生活气息的原创角色世界。

PROBLEM / 问题

设计挑战

让角色群像在保持各自性格差异的同时，形成统一、温暖的品牌气质。

SOLUTION / 解法

设计方案

统一三维比例、材质语言与柔和暖色光影，并延展到门店、包装与场景叙事。

02 / 设计目标DESIGN OBJECTIVES

明确目标，建立统一且有记忆点的视觉表达。

围绕品牌识别、内容传播与实际应用三个维度展开，让设计兼具视觉吸引力、信息效率与延展能力。

01核心目标一

强化视觉识别

建立清晰的核心符号与色彩记忆，让项目在不同媒介中保持一致。

02核心目标二

提升传播效率

优化内容层级和阅读路径，让受众快速理解项目主题与主要卖点。

03核心目标三

支持场景延展

形成可持续应用的视觉系统，适配线上、线下及后续衍生内容。

FINAL OUTCOME / 设计成果

形成从角色设定到商业空间想象的完整原创 IP 提案，具备系列化开发潜力。
